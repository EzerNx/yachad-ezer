# Registre des incidents de confidentialité · Yachad Ezer

La Loi 25 demande de **noter chaque incident**, même mineur, et de le garder **5 ans**.
Un incident, c'est par exemple : un accès non autorisé, une perte de données,
une demande lue par la mauvaise personne, un intercesseur qui partage une demande,
un mot de passe d'admin compromis.

## Que faire si un incident arrive

1. **Limiter les dégâts** tout de suite : mettre le compte en pause, changer les mots de passe,
   désactiver la clé compromise dans Supabase (Project Settings → API Keys).
2. **Évaluer le risque** de préjudice sérieux (données sensibles ? combien de personnes ?).
3. **Si le risque est sérieux** : aviser la Commission d'accès à l'information
   et les personnes concernées, le plus tôt possible.
4. **Noter l'incident** ci-dessous.
